## What shipped

### First-Run Tour
- 5-step spotlight coachmark tour auto-starting after onboarding completes
- Tour highlights: Dashboard, Transactions, Budgets, Reports, Settings
- Grandfather logic — existing users (pre-tour) skip the tour automatically via `tour_complete` meta flag
- Replay button in Settings → About to re-run the tour at any time
- Reduced-motion support — skips spotlight animation when user prefers reduced motion
- `data-tour` attributes on shell components for step targeting

### UX Friction-Reduction (Phase 1)
- **EmptyState primitive** — unified empty-state component with icon, title, description, and optional action slot
- **ContextMenu primitive** — right-click / long-press dropdown for contextual actions (edit, delete, etc.)
- **Input autofocus prop** — `autofocus` prop on Input primitive for keyboard-first flows
- **TransactionForm reorder** — amount field moved to top with autofocus for faster entry
- **TopBar utility bar** — removed dead hamburger menu icon; TopBar now shows only utility actions (theme, language)
- **BottomNav "More" sheet** — mobile secondary navigation moved into a slide-up sheet instead of cramming all items into the bottom bar
- **Dashboard cleanup** — removed inline quick-entry from dashboard; recent transactions list now uses EmptyState when empty
- **Transactions + Accounts lists** — adopted EmptyState for empty states and ContextMenu for row actions

- App icon and favicon updated to match VFD design system
