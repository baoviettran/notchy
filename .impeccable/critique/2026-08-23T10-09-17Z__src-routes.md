## Design Specificity Verdict
Machine metaphor carries hardest where money is displayed/captured (Quick Add tape window, VFD net-position readout, segmented VFD Progress meter with aria-valuetext, debt-free lamp). Reports surfaces go quiet: reports/trend hand-rolls generic div-bars while src/lib/components/charts/ sits unused; TopBar search is stock. Deterministic scan: CLI detector on src/routes = 0 findings (clean post-normalization). Browser overlay flagged cream-palette and gradient-text — both false positives against this brief (cream #F4EFE2 is the documented paper variant; no gradient exists in source).

## What's Working
1. Quick Add commits fully to the machine conceit while containing engineering truth.
2. Consequence framing as house style: write-off "remaining after this" live preview, undo by exact ID, numbers never adjectives for irreversibility.
3. Empty states that teach: sample budget scaled to user currency (VND ? 1_000_000 : 100).

## Priority Issues
1. [P1] Keyboard dead-end: TransactionForm.svelte has no <form>/submit binding; Enter does nothing. Fix: wrap in form with submit handler, keep saving guard.
2. [P1] Locale switch non-reactive: setLanguageTag() in settings.svelte.ts:24 doesn't re-render page bodies; Settings page stays in old language after clicking its own button. Fix: shared reactive locale module; delete per-component _locale bridges.
3. [P2] VND-scale figures break composition: dashboard hero break-all wraps mid-digit at billions; budgets dual-figure crowding; report tables overflow. Fix: compact notation (12,3 tr ₫) with exact figure available.
4. [P2] Dark --debit #E5484D on #1C1812 ~4.4:1 at text-sm — under AA for the color carrying most data. Fix: measured token lift.
5. [P3] Reports metaphor-quiet: wire existing charts/, value readout on hover/focus, skeleton loading branch.
