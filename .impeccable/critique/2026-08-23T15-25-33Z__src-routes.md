## Overall Impression

This is a rare thing: a personal-finance app where the metaphor does usability work instead of decorating it. The score moved 31 → 33 on the strength of error prevention and honest-money semantics. What's left is no longer craft drift — it's structural UX debt: repair paths (edit kind, delete undo) lag capture paths, and volume workflows (bulk cleanup) don't exist yet. The single biggest opportunity: make the repair path as fast as the capture path.

## What's Working

1. **Quick-add as a physical object** — single-line parser, mono VFD input, 250ms phosphor flicker on save, focus re-grab on window refocus. The best peak-end beat in the product; captures are never unacknowledged.
2. **Honest-money semantics enforced in code** — `Money.svelte` pairs glyph + tone so color never carries meaning alone, compacts visually while announcing full precision via `sr-only`.
3. **Consequence-framed destruction** — account deletion queries and states the real transaction count; write-off live-previews "remaining"; guards wired to actual data, not boilerplate warnings.

## Priority Issues

1. **[P1] Kind is frozen during edit** — `disabled={isEdit}` on all kind toggles (TransactionForm.svelte:199). A misfiled expense can't become a refund or transfer without delete-and-recreate. Fix: enable kind switching in edit mode (the transfer-fields branch already exists). Suggested command: `$impeccable shape`
2. **[P1] Transaction delete confirm is anonymous** — static body, no payee/amount/date restatement (transactions/+page.svelte:240-241), while lesser actions get richer feedback. Fix: interpolate payee · amount · relative date into the dialog; add undo toast (exact-ID undo machinery already exists). Suggested command: `$impeccable harden`
3. **[P2] No bulk operations on transactions list** — 50-row pages, per-row ContextMenus only; post-import cleanup means N × (menu → delete → confirm). Fix: multi-select with floating batch bar (delete / retag / change account) styled as a tape-segment strip. Suggested command: `$impeccable shape`
4. **[P2] Touch-target drift below the ≥44px bar** — `Button size="sm"` min-h-9 used for primary action rows (Filters, Import, accounts Add); kind toggles min-h-9. Fix: raise to min-h-11 under coarse pointers using existing pointer-fine variant infrastructure. Suggested command: `$impeccable adapt`
5. **[P2] Onboarding selection is color-only** — language/currency cards convey selection purely via border/tint (onboarding/+page.svelte:21-23, 112-113), no `aria-pressed`, violating the app's own "never color alone" rule at minute one of ownership. Fix: add `aria-pressed` + ✓ glyph. Suggested command: `$impeccable harden`

## Persona Red Flags

**Alex (power user):**
- Cannot change transaction kind when editing — misfiling costs delete+recreate
- Zero bulk ops; cleaning 30 imported rows = 30 × (open menu → delete → confirm)
- `n`/`/` shortcuts undiscoverable outside one empty-state string; a `?` shortcut-cheatsheet overlay would fit the faceplate aesthetic perfectly
- Prev/next pagination only; no jump-to-month despite SQL-backed filters supporting it

**Sam (keyboard + screen reader):**
- Onboarding selections border-color-only, no `aria-pressed` — a screen reader hears two identical buttons
- Net-worth chart non-visual reading depends entirely on LineChart's sr-only table; reports otherwise favor glow over data-as-text
- BottomNav More scrim click-only; dialog never links `aria-controls` to its trigger
- Keep: Money sr-only full precision, ContextMenu arrow/Home/End pattern, field errors with role="alert"

**Casey (distracted mobile):**
- Whole transaction row navigates on tap with ⋯ menu adjacent, no separation gutter — sloppy thumb near the amount launches navigation instead of menu
- Draft restore saves interruptions but `date` isn't in the draft — resume next morning silently files yesterday's entry under today's date
- Shell work exemplary (64px nav, 56px FAB, 44px paging arrows); risk concentrates in list rows and 36px sm buttons

## Minor Observations

- Budgets page has a loading branch but no error branch — failed load renders an empty page silently (siblings have ErrorState)
- Dashboard hero juggles truncate/break-all for long VND figures; Money's compact-toggle pattern should be extracted there
- Native checkbox (net-worth) vs custom toggles elsewhere breaks control vocabulary
- EmptyState icon identical `▮▯▯▯` everywhere, including error-adjacent contexts
- Duplicate toast appears but duplicated row isn't scrolled into view or highlighted
- Scroll position persists across pagination clicks; page 2 opens mid-list
